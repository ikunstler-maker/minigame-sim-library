# Підключення: що де лежить і як підключити

Стан на 25.11.2026. Більшість програм уже встановлена на цьому ноутбуці. Для нової гри Claude лише скопіює налаштування, а нові облікові записи знадобляться тільки там, де написано «для кожної гри своє».

## Підключення до Claude (файл `.mcp.json` у папці гри)

Claude копіює `templates/mcp.json` у корінь нової гри. Після цього **закрий і знову відкрий застосунок Claude** і дозволь сервери, коли спитає.

### Godot
- Працює сам, нічого натискати не треба.
- Якщо переносиш Godot в іншу папку, скажи Claude новий шлях.

### Blender
- **Перед роботою відкрий Blender.** Сервер у ньому вмикається сам (вкладка «MCP for Blender» на панелі, що відкривається клавішею N).
- Увімкнено безпечний режим (Claude не має доступу до файлів поза Blender і до мережі) і вимкнено збір статистики.
- Бібліотеку Poly Haven можна ввімкнути галочкою в тій самій панелі. AI-генератори (Tripo, Meshy) платні, ми їх не вмикали.

### ElevenLabs (звуки)
- Хмарне підключення, нічого встановлювати не треба.
- Щоб увімкнути: у застосунку Claude набери `/mcp`, вибери **elevenlabs** і натисни вхід. Відкриється сторінка ElevenLabs, там «Authorize».
- Безкоштовно 10 000 кредитів на місяць. Перед генерацією Claude каже, скільки звуків робить.

## Сервіси (для кожної гри своє)

### GitHub — резервна копія
1. У GitHub Desktop: **File → New repository**, назва гри, папка `Documents\GitHub\назва`.
2. Натисни **Publish repository**, галочка **Keep this code private** має стояти.
3. Скажи Claude назву. Вхід для git уже збережений (Git Credential Manager), тож Claude пушить сам.

### itch.io — гра для гравців
1. На itch.io: **Upload new project**, Kind of project — **HTML**, Viewport — **1280 × 720**, галочка **Fullscreen button**.
2. Скажи Claude адресу сторінки (наприклад, `ikunstler.itch.io/назва-гри`).
3. Claude відправить гру через butler (вхід уже збережений).
4. Один раз зайди в **Edit game**: біля файлу **html5** постав галочку **«This file will be played in the browser»** і натисни **Save**.
5. Пошта на itch.io має бути підтверджена, інакше файли не завантажуються.

### Render — онлайн-гра
1. **dashboard.render.com → + New → Web Service**, вибери репозиторій гри.
2. Root Directory — `server`, Runtime — Node, Build — `npm install --omit=dev`, Start — `node relay.js`, Instance — **Free**, Health Check Path — `/health`.
3. Дочекайся зеленого **Live** і надішли Claude адресу `https://….onrender.com`.
4. Безкоштовний сервер засинає після 15 хвилин без гравців, тож перше підключення може тривати до хвилини.

## Обережно

- **ACE-Step (музика)** двічі «повісив» ноутбук під час довгих треків: відеокарта Quadro M1200 слабка. Генеруй лише короткі шматки (20–30 с) і нічого не відкривай під час генерації. Інший варіант — онлайн-генератор (Suno).
- **Якість графіки** в іграх тримай «Середня» або «Низька»: на «Висока» ноутбук може гальмувати.
