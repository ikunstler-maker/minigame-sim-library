# Набір для нового ігрового проєкту

Тут зібрано все, за чим ми робили Rooftop Hide & Seek: правила роботи, налаштування всіх підключень і помилки, на які ми вже наступили. Цим набором ти зможеш почати нову гру так само, не повторюючи ці кроки з нуля.

## Що всередині

| Файл | Для кого | Про що |
|---|---|---|
| `README.md` | для тебе | цей файл: з чого почати |
| `01-pravyla-roboty.md` | для тебе | як ми працюємо: від ідеї до опублікованої версії |
| `02-pidkliuchennia.md` | для тебе | які програми й сервіси підключені, де вони лежать і як підключити їх наново |
| `03-pastky.md` | для тебе і для Claude | що вже ламалось і як ми це виправили |
| `templates/CLAUDE.project.md` | для Claude | правила, які Claude має прочитати в новому проєкті |
| `templates/mcp.json` | для Claude | готові налаштування підключень Godot, Blender, ElevenLabs |
| `templates/publish.ps1` | для Claude | скрипт, яким Claude відправляє гру на GitHub та itch.io |
| `templates/roadmap.md` | для обох | шаблон плану розробки |
| `templates/memory/` | для Claude | нотатки, які Claude пам'ятає про тебе між розмовами |

## Як почати нову гру (4 кроки)

**1. Нова папка з ігровою студією.** Попроси Claude в цій розмові: «Створи новий проєкт гри в папці `Documents\назва-гри` на основі Claude Code Game Studios і скопіюй туди starter-kit». Студія — це той самий набір агентів і команд (`/prototype`, `/start`), з яким ми працювали тут.

**2. Відкрий нову папку в застосунку Claude.** У вкладці Code вибери папку нової гри як робочу.

**3. Скажи Claude першим повідомленням:**

> Прочитай `starter-kit/templates/CLAUDE.project.md` і `starter-kit/03-pastky.md` і працюй за цими правилами. Скопіюй нотатки з `starter-kit/templates/memory/` у свою пам'ять. Потім `/prototype` — і ось моя ідея: …

**4. Дай Claude підключити сервіси** за `02-pidkliuchennia.md`. Більшість уже встановлена на цьому ноутбуці, тож для нового проєкту залишиться тільки:
- новий приватний репозиторій на GitHub (через GitHub Desktop, як `chibi-has`);
- нова сторінка на itch.io (Create new project);
- новий сервіс на Render, якщо гра буде мережевою.

## Що робиш ти, а що Claude

- **Ти:** описуєш ідею, граєш і кажеш, що подобається, а що ні; реєструєшся в сервісах і натискаєш «Дозволити»; приймаєш або скасовуєш зміни.
- **Claude:** пише код, моделює в Blender, перевіряє гру в браузері, зберігає версії, відправляє на GitHub та itch.io.

Паролі, ключі й коди з пошти ти ніколи нікому не надсилаєш, Claude теж. Усі входи йдуть через кнопку «Authorize» у твоєму браузері.
